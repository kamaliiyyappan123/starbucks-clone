## ✨ Features

- **Responsive Navigation** — Hamburger menu on mobile with smooth toggle animation
- **Animated Hero Section** — Floating drink image with CSS keyframe animation
- **Shop Page** — Product grid with 6 drinks, star ratings, and individual product pages
- **Product Detail Pages** — Order confirmation flow for Rose, Chocolate, and Green Mocha Frappuccinos
- **Delivery Section** — Uber Eats-style delivery landing page
- **App Section** — Mobile app promotion section
- **About Section** — Brand story layout
- **Contact Footer** — Social media links and navigation
- **Mobile-First Design** — Fully responsive across all screen sizes

## 🚀 Getting Started

### Run Locally

1. **Clone the repository**
   ```bash
   git clone https://github.com/your-username/starbucks-clone.git
   ```

2. **Navigate into the folder**
   ```bash
   cd starbucks-clone
   ```

3. **Open in browser**
   ```bash
   # Simply open index.html in your browser
   # Or use VS Code Live Server extension for best experience
   ```

### Deploy on GitHub Pages

1. Go to your repository **Settings**
2. Click **Pages** in the left sidebar
3. Under **Source**, select `main` branch and `/ (root)`
4. Click **Save** — your site will be live in a few minutes!

## 📱 Responsive Breakpoints

| Breakpoint | Layout |
|---|---|
| `> 1150px` | Full desktop layout |
| `991px – 1150px` | Slightly reduced padding |
| `768px – 991px` | Compact layout |
| `< 768px` | Mobile layout with hamburger menu |
| `< 364px` | Stacked footer links |
